# G. Sunil Kumar Reddy — Portfolio

A one-page portfolio built with the Next.js App Router, TypeScript, and SCSS Modules. The interface is framed as a desktop application window over a bright blue wallpaper, opening into a black editorial canvas with warm accent details, rounded navigation, a full transparent portrait cutout beside the name, and small project-flow diagrams. Motion is kept to CSS transitions and respects reduced-motion preferences.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build and validate

```bash
npm run typecheck
npm run build
npm start
```
